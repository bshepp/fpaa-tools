# GPIO control.
#
# The driver does `import RPi.GPIO`. That module is provided by rpi-lgpio, a
# drop-in replacement that routes to lgpio and works on every Pi including
# the Pi 5. Raspberry Pi OS Bookworm/Trixie ship it as `python3-rpi-lgpio`.
#
# It reports RPi.GPIO.VERSION == "0.7.2" for compatibility. There is no real
# RPi.GPIO 0.7.2: the original package stops at 0.7.1 on PyPI and does not
# work on a Pi 5. Do not install both -- they provide the same module.
rpi-lgpio>=0.6

# Edge capture (recommended for anything timing-sensitive — see README).
# Provides kernel-timestamped GPIO edge events.
gpiod>=2.1
